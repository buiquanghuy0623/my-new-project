# my-new-project
MÔ TẢ BÀI THỰC HÀNH TẠO VÀ ĐỒNG BỘ GITHUB REPOSITORY
Ý nghĩa các câu lệnh Git đã sử dụng:
- git init: Khởi tạo một Local Repository mới trong thư mục dự án.
- git remote add origin <URL>: Kết nối Local Repository với Remote Repository trên GitHub.
- git add README.md: Đưa file README.md vào Staging Area để chuẩn bị commit.
- git commit -m "Add README.md file": Lưu phiên bản thay đổi vào lịch sử Git kèm ghi chú.
- git push origin main: Đẩy mã nguồn đã commit ở máy local lên nhánh main trên GitHub.
